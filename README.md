# Dictionary and Word Lookup App

A responsive Dictionary and Word Lookup application created as **Task 28** of my **Web Development Internship at Veda Technology**.

## 📌 Project Overview

This project allows users to search for English words and view their:

- Definitions
- Parts of speech
- Multiple meanings
- Phonetic pronunciation
- Example sentences
- Audio pronunciation when available

The application retrieves dictionary data from a public API using the JavaScript Fetch API.

## 🎯 Objective

The main objective of this task was to practice:

- API consumption
- Fetch API
- Async/Await
- Error handling
- DOM manipulation
- Dynamic content rendering
- Multiple API results
- Audio pronunciation
- Responsive web design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- FreeDictionaryAPI

## ✨ Features

- Search for English words
- Display word definitions
- Display multiple parts of speech
- Display multiple meanings
- Display phonetic pronunciation
- Play pronunciation audio when available
- Browser speech synthesis as a fallback
- Example sentences
- Loading state
- Error handling
- Responsive design
